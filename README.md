# bambu-h2d-gateway

Local LAN Gateway for Bambu Lab H2D (and Bambu Lab X1 / P1 / A1 series) 3D Printers over MQTT TLS. Exposes real-time printer status via Fastify REST API and WebSocket stream.

---

## 🌟 Overview & Architecture

`bambu-h2d-gateway` acts as a local bridge between a Bambu Lab 3D Printer and modern web applications / home automation systems.

```
+------------------+         MQTT TLS (Port 8883)       +-----------------------+
|  Bambu Lab H2D   | ---------------------------------> |   BambuMqttClient     |
+------------------+   Topic: device/{SERIAL}/report    +-----------------------+
                                                                    |
                                                                    v
                                                        +-----------------------+
                                                        |  BambuMessageParser   |
                                                        +-----------------------+
                                                                    |
                                                                    v
                                                        +-----------------------+
                                                        |   PrinterStateStore   |
                                                        +-----------------------+
                                                                 /     \
                                                                /       \
                                                               v         v
                                                     +-------------+  +---------------+
                                                     | Fastify REST|  | WebSocket     |
                                                     | /api/printer|  | /ws           |
                                                     +-------------+  +---------------+
```

### Key Principles
- **Read-Only Safety**: Phase 1 reads telemetric status only. It does **NOT** issue write or control commands to the printer.
- **Bambu Studio Independence**: Runs completely independently on your LAN without requiring Bambu Studio or Bambu Handy.
- **Fault-Tolerant Parsing**: Resilient against unexpected or updated firmware payload schema changes.
- **In-Memory State**: Zero database overhead; state is safely managed in RAM.

## 🛠️ Installation & Setup

1. **Clone or navigate to project directory**:
   ```bash
   cd bambu-h2d-gateway
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` with your printer's credentials:
   ```ini
   BAMBU_HOST=192.168.1.100
   BAMBU_PORT=8883
   BAMBU_SERIAL=01S00A123456789
   BAMBU_ACCESS_CODE=12345678

   HTTP_HOST=0.0.0.0
   HTTP_PORT=3000

   LOG_LEVEL=info
   PRINTER_OFFLINE_TIMEOUT_MS=30000
   ENABLE_RAW_API=true
   ```

## 🔑 How to Obtain Bambu Printer Details

### 1. Printer IP Address (`BAMBU_HOST`)
- **On Printer Screen**: Go to `Settings` -> `Network` -> View IP address (e.g. `192.168.1.100`).
- **Or via Router**: Look for device hostnames starting with `Bambu` or `bblp` in your router's DHCP client list.

### 2. Printer Serial Number (`BAMBU_SERIAL`)
- **On Printer Screen**: Go to `Settings` -> `Device` / `System Info` -> `Serial Number`.
- **Physical Label**: Located on the back panel sticker of the machine.

### 3. LAN Access Code (`BAMBU_ACCESS_CODE`)
- **On Printer Screen**: Go to `Settings` -> `Network` -> `LAN Mode` / `Access Code`.
- **Note**: This is an 8-character password generated by the printer for local LAN communication.

## 📡 REST API Documentation

### 1. Health Check
- **Endpoint**: `GET /api/health`
- **Description**: Returns server health status.
- **Response**:
  ```json
  {
    "status": "ok"
  }
  ```

### 2. Get Normalized Printer State
- **Endpoint**: `GET /api/printer`
- **Description**: Returns normalized real-time status of the Bambu H2D printer.
- **Response Example**:
  ```json
  {
    "serial": "01S00A123456789",
    "online": true,
    "state": "RUNNING",
    "progress": 35,
    "temperatures": {
      "nozzle": {
        "current": 220,
        "target": 220
      },
      "bed": {
        "current": 60,
        "target": 60
      },
      "chamber": 32
    },
    "job": {
      "name": "model.3mf",
      "currentLayer": 120,
      "totalLayers": 350,
      "remainingTimeMinutes": 45
    },
    "fan": {
      "part": 100,
      "aux": 50,
      "chamber": 0
    },
    "ams": [],
    "lastMessageAt": "2026-08-22T10:00:00.000Z",
    "updatedAt": "2026-08-22T10:00:00.000Z"
  }
  ```

### 3. Get Raw MQTT Payload (Debug)
- **Endpoint**: `GET /api/printer/raw`
- **Description**: Returns the latest raw unparsed MQTT report JSON payload from the printer.
- **Requirement**: `ENABLE_RAW_API=true` in `.env`.

## 🔌 WebSocket Protocol

- **Endpoint**: `ws://localhost:3000/ws`

### Events Broadcasted

1. **Initial Connection & State Updates**:
   Sent immediately on client connection and on every telemetry message received from the printer.
   ```json
   {
     "type": "printer.state",
     "data": {
       "serial": "01S00A123456789",
       "online": true,
       "state": "RUNNING",
       "progress": 35,
       "temperatures": { ... },
       "job": { ... },
       "fan": { ... },
       "updatedAt": "2026-08-22T10:00:00.000Z"
     }
   }
   ```

2. **Printer Connection Status Change**:
   Broadcasted when the printer connection status changes (e.g. printer powered off or timeout).
   ```json
   {
     "type": "printer.connection",
     "data": {
       "online": false
     }
   }
   ```

## ❓ Troubleshooting

| Issue | Cause & Solution |
|---|---|
| `MQTT error` / `ECONNREFUSED` | Check printer IP (`BAMBU_HOST`) and make sure your printer is powered on and connected to the same LAN. |
| `MQTT disconnected` / `TLS Auth failed` | Double check `BAMBU_ACCESS_CODE` and `BAMBU_SERIAL`. Ensure `rejectUnauthorized: false` is used as Bambu printers use self-signed certs. |
| Printer marked `online: false` | If no MQTT message is received for `PRINTER_OFFLINE_TIMEOUT_MS` (default 30s), the gateway marks the state as offline. Sending any report will mark it back `online: true`. |
| Missing fields in `/api/printer` | Some fields (like `chamber` temperature or `job.name`) depend on printer hardware sensors and current state. The parser safely sets missing fields to `null`. |
